# details

## ヒント 1

単語の意味の特定をする。強勢記号のついていないデータとついているデータの両方を見て考える必要がある。

### ヒント 1-1

「歩く」と「見つける」だけ少しくせがある。

### 答え

2 単語になる（`jaka n-`「歩く」、`siba n-`「見つける」）。日本語のサ変動詞みたいなものだろうか。

### ヒント 1-2

主語が明示されていない文がいくつかある（文 8 、16 など）。主語はどのように表現されているか。

### 答え

動詞の prefix で表現される。

* `o-`「私が」
* `ti-`「君が」

所有表現も同じ prefix 。

## ヒント 2

強勢の規則を解明しておく。むずかしくない。

### 答え

終わりから数えて偶数番目の音節に強勢が置かれる。例外はない。

## ヒント 3

動詞の構造を探る。

単語の区切りがややむずかしい。
ヒントは、この言語は基本的に開音節であること。つまり、子音と母音の間で区切ることは考えなくてよい。

### ヒント 3-1

* 「～する」：何もつかない。
* 「～した」：`-ro` か `-ri` がつく。
* 「～しようとしている」：`-bona` か `-bone` がつく。

これらの使い分けは？

### 答え

主語が男性なら `-ri` や `-bona` 、女性なら `-ri` や `-bone` 。

なお、「私」や「君」と「ナマケモノ」は女性扱い。「クモザル」と「ジャガー」は男性扱い。

### ヒント 3-2

動詞の構造は次の通り。

* `o-`「私が」/ `ti-`「君が」/ ∅ その他
* 動詞の語幹
* `-ha-` / `-hi-` / ∅
* `-ro` / `-ri` / `-bona` / `-bone` / ∅

ただし、「食べる」の動詞の語幹が `kaba` だったり `kabe` だったり、「つかむ」の語幹が `wate` だったり `wata` だったりする。これらの違いは？

### 答え

やはり主語の性による。男性なら `-e` 、女性なら `-a` 。

## ヒント 4

動詞に `-ha-` / `-hi-` が挿入される条件を考える。これが一番むずかしい。

### ヒント 4-1

意味によって挿入されるわけではない。

### ヒント 4-2

強勢は若干関係するが、考えないほうが解きやすい（と思う）。強勢の位置を調整するために挿入するわけではない。

### ヒント 4-3

音節の数。

### 答え

動詞の suffix（`-ro` など）を除いて、音節が偶数個だったら `-ha-` / `-hi-` を挿入する。主語を表す音節（`o-` や `ti-`）もカウントすることに注意する。

{{< remark >}}
同じ動詞の語幹でも `-ro` がつくか `-bone` がつくかで強勢の位置が変わってしまうが、この言語ではそれは気にしないらしい。
実際、問題文の `wáte-hí-ri` は `wa` に強勢があるが、解答の `watá-ha-bóne` は `ta` に強勢がある。
{{</ remark >}}
