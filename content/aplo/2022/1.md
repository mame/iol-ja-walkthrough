# details

## ヒント 1

名詞はすぐにわかるが、動詞は語幹がどこかも見極めにくい。まずは名詞の suffix を考える。

### ヒント 1-1

名詞の suffix は `-ra` と `-rã` だけ。これらが双数を表すのはすぐにわかる。

`-ra` と `-rã` の使い分けは？

### ヒント 1-2

文の構造によって使い分けられる。また、`hẽ` もついでにわかる。

### 答え

* 主語が双数のとき、目的語がある文では `-rã` 、ない文では `-ra` が選ばれる。
* 主語が単数のとき、目的語がある文では直後に `hẽ` が置かれる。ない文では何も置かれない。

## ヒント 2

動詞の構造はややむずかしい。prefix や suffix から攻略しても解けなくはないが、双数に注目するとやりやすいと思う。

### ヒント 2-1

双数のある文にだけ登場する何かを探す。特に、「二人の子供が私たち二人を噛んだ」では双数が 2 回登場するのがヒント。

### 答え

双数のある文には `-mẽ-` が現れる。

### ヒント 2-2

`ti-mẽ-ra-mẽ-sa` から、「噛む」の語幹を探す。

「私たち二人が君を噛むだろう」の文との共通点を探せば良い。

### 答え

`-sa`「噛む」。

### ヒント 2-3

語幹が最後につくことがわかった。また、`-mẽ-` が主語や目的語の双数に対応していることもわかった。これを使うと語の構造がおおよそわかる。

### ヒント 2-4

`-rã-` はひっかけ。

### 答え

`-rãpio`「温かい」や `-rãprâ`「塗られている」の語幹の一部。

## ヒント 3

動詞の構造をまとめる。目的語のない文から考える。

### ヒント 3-1

おおよそ次の構造がわかる。

* `jy-` / `ka-` / ∅
* `mẽ-`（主語が双数） / ∅（主語が単数）
* `sy-` / `kua-`
* 語幹

### ヒント 3-2

`sy-` と `kua-` の使い分けを考える。（いますぐわからなければ、目的語のある文を見ながら後で考えるのもよい）

### 答え

* `sy-` 穀物につく
* `kua-` 果実につく
* 人間には何もつかない

### ヒント 3-3

`jy-` と `ka-` の使い分けを考える。目的語のある文も見ながら考えるとよい。

### 答え

* `ka-`「～するだろう」
* `jy-` それ以外の自動詞

`jy-` の文は現在形だったり過去形だったりするが、これは動詞によって現在形か過去形かが決まっていると考えれば良い。

{{< remark >}}
解答によると、状態動詞は現在形、動作動詞は過去形とのこと。`jy-` は状態を表し、動作動詞は動作が終わった状態を表すと考えられるかも。
{{</ remark >}}

## ヒント 4

他動詞の文の構造は次の通り。

* `ka-` / ∅
* `ka-` / `ti-` / `ri-`
* `mẽ-` / ∅
* `ra-` / `a-` / ∅
* `mẽ-` / ∅
* `sy-` / `kua-`
* 語幹

### ヒント 4-1

`ka-` / `ti-` / `ri-` の使い分け。

### 答え

主語の人称。

* `ri-` 一人称
* `ka-` 二人称
* `ti-` 三人称

直後に `mẽ-` が続く場合は主語が双数になる。

### ヒント 4-2

`ra-` / `a-` / ∅ の使い分け。

### 答え

目的語の人称。

* `ra-` 一人称
* `a-` 二人称
* ∅ 三人称

直後に `mẽ-` が続く場合は目的語が双数になる。

### ヒント 4-3

`sy-` と `kua-` の使い分け。ヒント 3-2 も参照。
