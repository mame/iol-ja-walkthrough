# details

## ヒント 1

とにかく問題文をしっかり読む。

### ヒント 1-1

話し手はすべて「アカン人男性」。よって Enu 、Kofi 、Kobina 、Yaw はすべて男性。

### ヒント 1-2

「一つの空欄に二単語以上入ることもある」を読み落とさないこと。

### ヒント 1-3

Yaw の発言で `Yɛfrɛ me nuanom Thema ne ___.` とあるが、Yaw の `nuanom` が Thema ともう一人だけとは限らない。

### ヒント 1-4

呼称に該当する人名は必ずすべて書かれている。A と B と C が `nuanom` であるにもかかわらず `Yɛfrɛ me nuanom A ne B.` とだけ書かれるようなことはない。

## ヒント 2

`-nom` の意味を見破ることが重要。

### ヒント 2-1

`-nom` は「子ども」ではない。

### ヒント 2-2

`-nom` は形式的なもの。出現する文をよく見る。

### 答え

`-nom` は複数形。

## ヒント 3

`nua` の意味を考える。Kobina の `nua` が Yaw であり、Yaw の `nua` が Thema であることがヒント。

### ヒント 3-1

家系図に 2 世代しかいないことが重要。

### ヒント 3-2

`nua` が別の世代を指す言葉（「親」や「子」など）だとしたら、Kobina → Yaw → Thema で 3 世代にまたがってしまう。

### ヒント 3-3

`nua` は同世代を表す可能性が高いので、一旦そのように仮説を立てて進める。

Enu の `nua` に Awotwi がいることから、Enu と Nsia の位置にあたりがつく。

### ヒント 3-4

`nua` は「兄弟姉妹」的な意味で、Enu と Nsia は Awotwi の兄弟。

Kobina の `nua` が Yaw と Ama であり、Yaw の `nua` が Thema と誰かになるような位置関係を探す。
単純な「兄弟姉妹」では見つからないので、`nua` の意味を考え直す必要がある。

### ヒント 3-5

平行いとこ。

### 答え

`nua` は、「（普通の日本語の意味での）兄弟姉妹、父の兄弟の子、母の姉妹の子」を表す。

Kobina 、Yaw 、Ama 、Thema の位置が確定する（子世代の真ん中の兄妹が Yaw と Ama 、Yaw の左が Kobina 、Ama の右が Thema）。

あとは丁寧に埋めていく。
