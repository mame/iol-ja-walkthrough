# details

## ヒント 1

まずは各単語の意味と役割を特定していく。単語自体に複雑な変化はなく、簡単に特定できるはず。

### ヒント 1-1

`-bə` は分離する必要がある。

### ヒント 1-2

最後から 2 番目の単語はとても難しいので後回しにする。

### 答え

* 自動詞：S - V - ? - `ne`
* 他動詞
  * 主語が一人称単数と二人称単数：S`bə` - O - V - ? - `ne`
  * 主語がそれ以外：S - `kəmə` - O - V - ? - `ne`

## ヒント 2

最後から 2 番目の単語を考える。主語と目的語に合わせて表を埋めていくとよい。

### ヒント 2-1

子音と母音を分けて表を作るとよい。`kɤ` なら、`k` と `ɤ` に分ける。

### ヒント 2-2

子音については、単複を無視して表を作るとよい。
母音については、単複を考慮して表を作る必要がある。

### ヒント 2-3

子音のテーブル（現在 / 過去）

| 主語＼目的語 | 一人称     | 二人称     | 三人称     | 自動詞     |
|--------------|------------|------------|------------|------------|
| 一人称       | -          | `k-`/`t-ʔ` | `k-`/`t-ʔ` | `k-`/`t-ʔ` |
| 二人称       | `r-`/？    | -          | `k-`/`t-ʔ` | `k-`/`t-ʔ` |
| 三人称       | `r-`/`tʰ-` | `r-`/`tʰ-` | -          | -          |

？に入る部分を埋める。（三人称の自動詞は問われないので放置してよい）

### ヒント 2-4

上三角と下三角。

### 答え

`tʰ-` が入る。

### ヒント 2-5

母音のテーブル

| 主語＼目的語 | 一人称単数 | 一人称複数 | 二人称単数 | 二人称複数 | 三人称単数 | 三人称複数 | 自動詞 |
|--------------|------------|------------|------------|------------|------------|------------|--------|
| 一人称単数   | -          | -          | ？         | ？         | `ɤ`        | ？         | `ɤ`    |
| 一人称複数   | -          | -          | `i`        | `i`        | `i`        | `i`        | `i`    |
| 二人称単数   | `ɤ`        | ？         | -          | -          | `u`        | ？         | `u`    |
| 二人称複数   | ？         | ？         | -          | -          | ？         | `an`       | ？     |
| 三人称単数   | `ɤ`        | `i`        | ？         | ？         | -          | -          | -      |
| 三人称複数   | ？         | `i`        | `u`        | `an`       | -          | -          | -      |

規則性を見出して、？に入る部分を埋める。

### 答え

主語または目的語のいずれかに

* 一人称単数が出現したら `ɤ`
* それ以外で、一人称複数が出現したら `i`
* それ以外で、二人称単数が出現したら `u`
* それ以外で、二人称複数が出現したら `an`

表にすると次の通り。

| 主語＼目的語 | 一人称単数 | 一人称複数 | 二人称単数 | 二人称複数 | 三人称単数 | 三人称複数 | 自動詞 |
|--------------|------------|------------|------------|------------|------------|------------|--------|
| 一人称単数   | -          | -          | `ɤ`        | `ɤ`        | `ɤ`        | `ɤ`        | `ɤ`    |
| 一人称複数   | -          | -          | `i`        | `i`        | `i`        | `i`        | `i`    |
| 二人称単数   | `ɤ`        | `i`        | -          | -          | `u`        | `u`        | `u`    |
| 二人称複数   | `ɤ`        | `i`        | -          | -          | `an`       | `an`       | `an`   |
| 三人称単数   | `ɤ`        | `i`        | `u`        | `an`       | -          | -          | -      |
| 三人称複数   | `ɤ`        | `i`        | `u`        | `an`       | -          | -          | -      |
