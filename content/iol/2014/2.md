# details

## ヒント 1
`-dɔ` 、`-n` 、`-gɔ` の suffix がつくかどうかが問われている。

### ヒント 1-1

suffix のつき方が同じパターンを集めて、共通点を考え、分類する。

### ヒント 1-2

一旦、`-dɔ` と `-gɔ` を同一視するとよい。

### ヒント 1-3

次の 3 つのパターンに分類できる。

* 単数形のみ `-dɔ`/`-gɔ` がつくパターン
* 複数形のみ `-dɔ`/`-gɔ` がつくパターン
* 単数形と複数形に `-dɔ`/`-gɔ` がつくパターン

それぞれに共通する特徴を考える。

### ヒント 1-4

単語だけ見ていても解けない。意味が関係する。

### 答え

* 生き物・道具：複数形のみ `-dɔ`/`-gɔ` がつく
* 果物：単数形と複数形に `-dɔ`/`-gɔ` がつく
* その他：単数形のみ `-dɔ`/`-gɔ` がつく

## ヒント 2

`-dɔ` と `-gɔ` のどちらがつくか、`-n` がつくかつかないか。
（情報が少なく、非常にむずかしい）

### ヒント 2-1

生き物と道具と果物と、その他で完全に別のルールになっている。

どちらから考えても良いが、ここでは生き物と道具と果物に注目する。

### 答え

生き物と道具と果物においては、`-dɔ` と `-n` がセットになっている。`-dɔ` を外すときは `-n` をつけ、`-n` を外すときは `-dɔ` をつける。
`-gɔ` は `-n` がつかない単語にのみ使われる。

「とりあえず `-gɔ` をつけ、語末が `-ngɔ` になった場合は `-dɔ` に変化する」と言っても良い。

{{< remark >}}
果物で `-dɔ` と `-n` がセットになっている例はないので、かなり察する力が必要。
{{</ remark >}}

### ヒント 2-2

その他のものに注目する。

### 答え

その他のものには `-n` の有無にかかわらず `-dɔ` をつける。`-gɔ` をつけることはない。
