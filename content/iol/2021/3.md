# details

## ヒント 1

共通要素を探せば、だいたいの単語の意味はわかるはず。prefix や suffix が大きいので、語幹を慎重に特定する。

## ヒント 2

動詞の変化を解明する。prefix と suffix それぞれを切り出して考える。

### ヒント 2-1

prefix は、`bi-` と `le-` がある。それぞれの意味は？

### 答え

時制。現在なら `bi-` 、過去なら `le-` 。

### ヒント 2-2

suffix は、`-si` が付く場合とつかない場合がある。

`gisi` だけちょっと特別。

### 答え

主語が複数なら `-si` がつく。

`gisi`「見る」に `-si` がつくと `gisesi` に変化する。

## ヒント 3

語順をきちんと理解する。結構くせがあるので注意。

### 答え

* 平叙文は「動詞 - 目的語 - 主語」。
* 疑問文は、疑問の対象が最初に来る。
  * 主語について聞く場合は「疑問詞 - 主語 - 動詞 - 目的語」。
  * 目的語について聞く場合は「疑問詞 - 目的語 - 動詞 - 主語」。

## ヒント 4

「この」「その」、形容詞、疑問詞の prefix を整理する。

### ヒント 4-1

修飾対象によって prefix が変わる。比較的規則性がある。

ただし、分類に若干くせがある。

### ヒント 4-2

彼らの生活にとって重要度の高そうなものが、特別な prefix になっている。

諸島での生活で重要そうなものは？

### 答え

`na`「この」、`wena`「その」の prefix は次の通り。

* 男：`mto-`
* 女・動物：`mina-`
* 子ども：`magudi-`
* カヌー：`make-`
* その他のもの：`makwe-`

修飾対象が複数の場合、`-si-` が挿入される。

形容詞・疑問詞の prefix は次の通り。

* 男：`te-`（数字と疑問詞の前）/ `to-`（形容詞の前）
* 女・動物：`na-`
* 子ども：`gudi-`
* カヌー：`ke-`
* その他のもの：`kwe-`

形容詞・疑問詞の prefix に `ma-` をつけると「この」「その」の prefix になる（ただし男のみ若干特別）。
