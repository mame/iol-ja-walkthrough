# details

## ヒント 1
単語の同定をした上で、名詞の `va-` と `m-` の prefix の意味を考える。

### 答え
`va-` は複数、`m-` は単数。

## ヒント 2
動詞の prefix が主題。`a-` 、`va-` 、`vam-` 、`am-` 、`ava-` など多様な prefix がついている。

### ヒント 2-1
名詞の単数・複数が `m-` と `va-` だったので、それを参考に prefix を分解する。

### ヒント 2-2
`a-` 、`va-` 、`-m-` 、`-va-` の 4 つに整理できる。

### ヒント 2-3
`a-` と `va-` は主語の単複を、その後の `-m-` と `-va-` は間接目的語（ものを受け取る人）の単複に対応している。これらはある条件で省略可能。

### 答え
* 語順が「主語 動詞 直接目的語 間接目的語」の場合、これらの prefix はすべて必須。
* 語順が「主語 動詞 間接目的語 直接目的語」の場合、これらの prefix はすべて省略可能。
  * ただし、間接目的語の単複（`-m-` と `-va-`）が書かれる場合、主語の単複（`a-` と `va-`）は省略不可。
