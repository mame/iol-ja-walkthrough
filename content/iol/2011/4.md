「chili」（トウガラシ）を中心に、関係しそうなものを拾い出す。

### さらなるヒント

`chilli` と `a-chilli` と `chil-atl` がトウガラシ関係の語と思われる。

選択肢では、「chili」（トウガラシ）、「chili water」（トウガラシの水）、「water pepper」（水からし）。

この中で、「chili」（トウガラシ）になるのはどれか。また、ほかにどのような仮説が立つか。他の選択肢も見ながら考える、

### 答え

単純に `chilli` =「chili」（トウガラシ）。

`achilli` と `chilatl` は「chili water」か「water pepper」のどちらか。
この時点では確定しないが、いずれにしても `a-` や `-atl` は水と思われる。
選択肢に `atl` と「water」があるので、これは確定。

## ヒント 2

`calhuah` と `a-calhuah` が何かを考える。

### ヒント 2-1

`a-calhuah` は水に関係すると思われる。残る選択肢で水に関係しそうなのは 1 つしかない。

### 答え

`a-calhuah` は「canoe owner」（カヌーの持ち主）。

### ヒント 2-2

「カヌーの持ち主」から「水」の要素を抜いた概念を選択肢から探す。

### 答え

`calhuah` は「master of house」（家の主人）。

おそらく `cal` が「家」、`a-cal` が「カヌー（水の家）」、`huah` が「持ち主・主人」だと当たりがつく（`cal` と `huah` は逆の可能性もある）。

## ヒント 3

名詞の区切りを考えて考察する。

### ヒント 3-1

`cone-huah-capil` と `oquich-totol-tzintli` が 3 単語以上を結合してできている。
選択肢から、意味の多そうな単語を探す。

### ヒント 3-2

「revered turkey-cock」（尊敬される七面鳥の雄）はおそらく 3 単語くらいになりそう。これはどちらの選択肢と考えられるか。

### ヒント 3-3

`cone-huah-capil` は `huah`（「持ち主・主人」または「家」）を含んでいる。「尊敬される七面鳥の雄」がどちらかの要素を含むとは考えにくい。

よって `oquich-totol-tzintli` =「revered turkey-cock」（尊敬される七面鳥の雄）と仮定する。

3 つのうち、「尊敬される」に対応する語はどれかを考える。

### ヒント 3-4

「revered grandfather/ancestor」（尊敬される祖父・祖先）と「grandfather/ancestor」（祖父・祖先）の選択肢と合わせて、整合するものを探す。

### 答え

* `tzintli` =「revered」（尊敬される）
* `col-tzintli` =「revered grandfather/ancestor」
* `colli` =「grandfather/ancestor」

`oquich` を使う単語は 3 単語あり、「revered」は 2 回しか出現しないので整合しない。

`totol` が「revered」である可能性を厳密に否定するのはちょっと大変。

* `totol` が「revered」だとする（形容詞が真ん中に出現するのはやや不自然だが）。
* 全体的に `-tl` という suffix が見られることを踏まえると、`te` が「grandfather/ancestor」（祖父・祖先）。
* `te` を持つ単語は `tehuah` と `tetlah` の 3 つあり、「祖父・祖先」の数と合わない。

## ヒント 4

`oquich` が「雄・男」とわかったので、`oquich-huah` や `oquich-cone-tl` に当てはまりそうなものを考える。

### さらなるヒント

`cone-tl` が存在することも合わせて考える。

### 答え

* `oquich-huah` =「wife」（妻、「男 - 持つ人」）
* `oquich-cone-tl` =「boy」（少年、「男 - 子ども」）
* `cone-tl` =「child」（子ども）

他の選択肢も同様に決まる。

## ヒント 5

問 (b) のためには、suffix の規則を理解する必要がある。`-li` と `-tl` はどちらを選ぶべきか。

### ヒント 5-1

`-tzintli` は `-li` という suffix ではなく、そういう単語。他の `-li` の用例から考えればよい。

### ヒント 5-2

`-lah` と `-tlah` も同じ規則で選ばれる。

### 答え

* `-l` で終わっていたら `-li` をつける。それ以外なら `-tl` をつける。
* ただし、`-capil` 、`-huah` 、`-lah/-tlah` 、`-tzintli` には何も付けない。
