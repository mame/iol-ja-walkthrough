# details

## ヒント 1
明らかに似ている単語があるので、グループ化して観察する。

### さらなるヒント
同じグループで、`z` と `ž` と `ɣ` が入れ替わることがある。
`z` が `ž` に変わると意味がどう変わるか、`ž` が `ɣ` に変わると意味がどう変わるかなどを考える。

### 答え
`z` がもっとも程度が弱く、`ž` が中くらい、`ɣ` がもっとも程度が強い。

## ヒント 2
「a thin liquid is being squeezed」の訳をどうするか。
`šli` が関連することはあきらかだが、`z` と `ž` と `ɣ` が含まれない。

### さらなるヒント
注釈をよくみる。

### 答え
`z` と `ž` と `ɣ` の無声音版がそれぞれ `s` と `š` と `x` で、これらも同じ関係にある。
