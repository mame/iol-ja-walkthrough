# details

## ヒント 1

動詞形 A 、動詞形 B への変換の大まかな傾向をつかむ。

### さらなるヒント

* 基底形から動詞形 A への変換は、原則として、`hin` / `hun` を後置する。
* 基底形から動詞形 B への変換は、原則として、`it` / `ut` を後置する。

これらの使い分けは？

### 答え

基底形の母音が `u` なら `hun`/`ut` 、それ以外なら `hin`/`it` 。

基底形が `u` とそれ以外の母音を同時に含むケースは、この問題では出てこないので気にしなくて良い。

## ヒント 2

基底系から動詞形 A への変換時の母音の変化を列挙し、規則を見つける。

### ヒント 2-1

母音 `i` や `u` が挿入される例がある（`qilk`→`qil-i-k-hin` など）。この規則は比較的わかりやすい。

### 答え

動詞形 A への変換時、語末の二重子音の間に `i`/`u` が挿入される。`hin` を付けるときは `i` 、`hun` を付けるときは `u` を挿入する。

### ヒント 2-2

長母音が短母音になったり、母音の種類が変わったりする例がある。

* `aa` が `a` に変わる（`saap`→`saphin` など）
* `ii` が `ee` や `e` に変わる（`qilii`→`qilee-hin` や `hibiiy`→`hibey-hin`）

これは、2 段階の変化が起きていると考えるとわかりやすい。

### ヒント 2-3

まず母音の種類が変化し、それから母音の長さが変化する。

### 答え

次の変換を順に行う。

* `ii`→`ee` 、`uu`→`oo` に置き換える
* 語末が `-VVC` の場合、`-VC` に置き換える（短母音化）
* 語末が `-VCC` の場合、`-VCVC` にする（挿入する母音は、`hin`/`hun` と同じもの）
* 最後に、`hin`/`hun` を付加する

## ヒント 3

基底系から動詞形 B への変換時の母音の変化を列挙し、規則を見つける。

### ヒント 3-1

`ii`→`ee` 、`uu`→`oo` は動詞形 A と同じ。

しかし、`-VVC` を短母音化する規則は単純には当てはまらない。短母音化する条件を特定する。

### ヒント 3-2

短母音化するのは次の 2 パターンに分けられる。

* `hoyoo`→`hoyot` と `qilii`→`qilet`
* `mooxl`→`moxlit` と `wuuwl`→`wowlut`

これらを説明できるよう、変換規則を改良する必要がある。

### 答え

* `ii`→`ee` に置き換える（`uu`→`oo` は置き換えない？）
* 語末が `-VV` の場合、`-V` に置き換え（短母音化）、`-t` を付加する
* 語末が `-VVC` の場合、そのまま `-it`/`-ut` を付加する
* 語末が `-VVCC` の場合、`-VCC` に置き換え、`-it`/`-ut` を付加する

## 余談

変換規則として考えるとずいぶん複雑になってしまうが、背景にある考え方としては「三重子音を避けたい」「長母音の閉音節を避けたい」というものらしい。

つまり、基底形に単純に `hin`/`hun`/`it`/`ut`/`t` を付加し、`ii`→`ee` と `uu`→`oo` の変換をしたうえで

* 三重子音 `-CCC-` になっている箇所は `-CVCC-` にする（挿入する母音は、直後の母音）
* 長母音の閉音節 `-CVVC-` は、短母音化して `-CVC-` にする

の 2 つの規則で説明できる。

`saap` や `huluus` のように、基底形には長母音の閉音節がある。
おそらく、実際には動詞形 A や B などの形でしか発音されることはなく、基底形はそれらの発音から再構築された概念上の原形を表している、ような気がする。
