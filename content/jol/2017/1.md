# details

## ヒント 1

「形容詞 名詞」の語順。形容詞に suffix がついている。

## ヒント 2

suffix は、形容詞によらず `-ый` / `-ая` / `-ое` の 3 つ。名詞に応じて変わる。

### 答え

* 子音で終わる名詞（男性名詞）なら `-ый` を使う
* `-a` で終わる名詞（女性名詞）なら `-ая` を使う
* `-o` で終わる名詞（中性名詞）なら `-ое` を使う

{{< remark >}}
これはこの問題のデータでの条件であり、実際のロシア語はもう少しいろいろあるらしい。
{{</ remark >}}

# /details
