# details

## ヒント 1

アラビア文字の基本的な特徴を知っていることは前提とされていそう？

### さらなるヒント

アラビア文字の基礎知識

* 右から左に書く
* 母音は省略されがち
* 各文字は語頭形・語中形・語末形を持つ（場所によって形が変わることがある）

## ヒント 2

明らかに同じ形の文字を探すことで、選択肢をグループ分けする。

* 選択肢 a 、d 、f 、g の最後（左端）の文字
* 選択肢 b と h の最初（右端）の文字
* 選択肢 i と j の最後（左端）の文字

### 答え

* { a, d, f, g } = { 2, 4, 9, 10 }
* { b, h } = { 3, 5 }
* { i, j } = { 6, 7 }
* { c, e } = { 1, 8 }

## ヒント 3

* { i, j } = { 6, 7 } の判別は、`m` の文字を考えるとよい。
* { c, e } = { 1, 8 } の判別は、真ん中に `r` があること。
* { b, h } = { 3, 5 } の判別は、`l` の文字が手がかりになる。

## ヒント 4

{ a, d, f, g } = { 2, 4, 9, 10 } は `k` の文字、`w` の文字を探すとよい。

### さらなるヒント

最後に残る { a, f } = { 2, 10 } の判別はむずかしい。強いて言えば `b` の文字。
